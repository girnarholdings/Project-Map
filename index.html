02The market loop

Seven reports in. One page out.

Overnight, the dream reads every report the fleet produced — one source at a time, so a five-megabyte dashboard never shares a context window with a bookmark — all on the local model, in about five and a half minutes.

It writes the page that matters: ranked edges with catalyst, invalidation and conviction; the conflicts between reports; a watch list. Agreement across sources is the product, and a missing source is named, never quietly dropped.

05The agent loop

Engineered to finish.

"Researches forever, answers never" is designed out. Every call is fingerprinted so it cannot repeat itself, every tool has a budget, and the loop is told to wrap up — then has its tools taken away — before it can spin.

A turn is a row, not a thread: it checkpoints after every model call and every tool result, so a restart is visible and a retried request reuses the run instead of doing the work twice.

# one turn
for step in 0..8:
  if step >= 5: inject wrap-up
  if step >= 7: tools off → answer from material
  call orchestrator →
    tool call?
      seen before      → "synthesize instead"
      over budget      → "answer now"
      dangerous        → approval card
      else             → run · checkpoint
    answer?  → persist · done

07Memory — the moat

Everything it learns, everyone remembers.

One memory pool — vector plus full-text search — shared by Hatch, every coding harness and the dream. It recalls before assuming, retains what lasts, and reflects across many memories at once. A nightly hygiene pass deduplicates and reconciles it; the first one retired 208 stale facts.

The skill flywheel: when something goes wrong, Hatch writes the lesson down as a skill it loads next time, and a weekly reflection audits them.

08Human-gated

Power, with a hand on the switch.

Anything consequential — running commands on a machine, writing code, sending a message, changing a routine, rendering video — raises an approval card first: what it wants to do, why, and the exact arguments.

One tap from the phone or Telegram: once, for the session, or no. An approval opens a ten-minute trust window for that tool — sudo, not a click-farm.

09The fleet

Three machines and a bus.

Dreams, cron reports, heartbeats and machine-to-machine work all ride one message bus. Every turn sees the last eight hours of fleet life — as context, never as commands — and any machine can hand Hatch a job.

When a pipeline fails, the bus tells Hatch; it diagnoses, fixes or stands down, files the lesson and reports back.
